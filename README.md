A Machine Learning project for Credit Card Fraud Detection.
- Preprocessed the data using Imputation, Log Transformation, and Feature Scaling.
- Used Logistic Regression, Decision Tree, and Random Forest classifiers.
- Used Cross-Validation and GridSearchCV for model evaluation and hyperparameter tuning.
- Evaluated the models using Precision, Recall, F1-Score, and Confusion Matrix.
- Used Precision-Recall Curves to analyze the trade-off between Precision and Recall.
- Focused mainly on Recall due to the importance of detecting fraudulent transactions.
